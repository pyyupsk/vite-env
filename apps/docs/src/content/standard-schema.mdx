vite-env supports [Standard Schema v1](https://standardschema.dev), a shared interface that many TypeScript validators implement. Use `defineStandardEnv` instead of `defineEnv`, and add `_standard: true`.

## Usage

```ts
import { defineStandardEnv } from "@vite-env/core";
import * as v from "valibot";

export default defineStandardEnv({
  _standard: true,
  server: {
    DATABASE_URL: v.pipe(v.string(), v.url()),
    PORT: v.optional(v.pipe(v.string(), v.transform(Number)), "3000"),
  },
  client: {
    VITE_API_URL: v.pipe(v.string(), v.url()),
  },
});
```

`_standard: true` tells the plugin to validate with Standard Schema. The plugin does not load Zod, so you do not need Zod installed.

Client keys must still start with `VITE_`. To use a different prefix, set `clientPrefix`:

```ts
export default defineStandardEnv({
  _standard: true,
  clientPrefix: "APP_",
  server: {
    DATABASE_URL: v.pipe(v.string(), v.url()),
  },
  client: {
    APP_API_URL: v.pipe(v.string(), v.url()),
  },
});
```

## Supported adapters

Any library that implements `StandardSchemaV1` works:

| Library       | Notes                           |
| ------------- | ------------------------------- |
| Valibot       | Native Standard Schema support  |
| ArkType       | Native Standard Schema support  |
| Effect Schema | Via `@effect/schema` adapter    |
| TypeBox       | Via `@sinclair/typebox` adapter |

## Type generation

With Standard Schema, every field in `vite-env.d.ts` is a `string`. Standard Schema gives no common way to read a validator's output type at runtime.

```ts
// vite-env.d.ts when using defineStandardEnv
declare module "virtual:env/server" {
  const env: {
    readonly DATABASE_URL: string; // always string, even if you coerce to number
    readonly PORT: string;
    readonly VITE_API_URL: string;
  };
}
```

If you want inferred `number`, `boolean`, or literal union types, use `defineEnv` with Zod.

## vs Zod path

Both give the same result at runtime: a frozen `env` object. They differ here:

|                 | Zod path              | Standard Schema path                    |
| --------------- | --------------------- | --------------------------------------- |
| Import          | `defineEnv`           | `defineStandardEnv` + `_standard: true` |
| Generated types | Inferred from schema  | All `string`                            |
| Zod required    | Yes                   | No                                      |
| Preset support  | Yes (`presets` array) | Not yet                                 |
